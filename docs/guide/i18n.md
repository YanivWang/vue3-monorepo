# 国际化（i18n）

**PC 管理端**（模板与 `create-app` 产物结构一致）使用 [Vue I18n](https://vue-i18n.intlify.dev/) 与 **Element Plus 语言包**；语言状态与 `app` 侧 store 联动。H5 若启用多语言，建议沿用同一套「运行时切换 + 持久化键」的约定，具体以**当前 H5 业务应用**内实现为准（模板源见 `apps/h5/h5-template`）。

## PC 管理端

- 语言包与词条目录：一般在 `src/locales`（`zh-CN` / `en` 等），以应用内实际路径为准。
- 启动顺序：在 `main.ts` / `plugins` 装配流程中在路由就绪前完成 I18n 与 Element Plus 的 locale 同步（与 [架构说明](./architecture.md) 中 `bootstrap` / `setupPlugins` 一致）。
- 与主题、布局相关的「界面语言」应通过**单一数据源**（如 `app` store 中的 `language`）驱动，避免多处硬编码。

## 开发约定

- 新页面文案优先走 i18n 词条，**避免**在模板中写死大段中文/英文；公共词条放在共享 locale 分模块维护。
- 与后端联调的「可翻译字段」由接口返回时，前端的展示与格式化（日期、数字）仍通过 `dayjs` / 当前 locale 处理。

## 与权限、主题的关系

- 语言切换**不改变**权限与路由；仅影响 `ElMessage`、表单校验提示等展示语言。
- 若需随系统深浅色切换**组件库**的文案资源，请保持与 Element Plus / Vant 的 API 推荐用法一致（见 [主题与暗黑模式](./theme.md)）。
