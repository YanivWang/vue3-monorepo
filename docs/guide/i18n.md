# i18n 国际化

**语言包懒加载**：Admin 与 H5 均已通过按语言的动态 `import()` 拆分为独立 chunk，启动只拉当前语言与 fallback，切换语言时再按需合并词条。

**Admin 与 H5 模板**均使用 [Vue I18n](https://vue-i18n.intlify.dev/)，并与 **Element Plus / Vant** 组件库语言包联动：

- **懒加载**：`@vue3-monorepo/shared/locale` 中 zh-CN、en-US 词条按语言 **动态 `import()`** 拆成独立 chunk；启动时仅加载当前界面语言与 fallback（默认再加载 `zh-CN`）。切换语言时按需拉取对应 chunk 并 `mergeLocaleMessage`。
- **PC Admin**：`apps/pc/pc-admin-template/src/main.ts` 在 `setupPlugins` 前执行 `loadInitialAdminI18n()`（内部 `preloadSharedLocales`）。`App.vue` 里 Element Plus 的语言包是**静态 import**（`zh-cn` / `en` 两份体积很小），随 `appStore.language` 变化切 `ElConfigProvider` 的 `locale`。
- **H5**：`apps/h5/h5-template/src/main.ts` 在 `app.use(i18n)` 前执行 `loadInitialH5I18n()`；业务词条位于 `src/locales/bundles/`，与 shared 基础词条分层合并；Vant `Locale` 由 `composables/useI18n.ts` 的 `applyVantLocale()` **动态 `import()`**，并 `watch` 当前 locale 自动同步。

语言状态与各端 `app` store 的 `language` 字段持久化联动。首屏语言的解析顺序：Pinia 落盘的 `language`（Admin 读 `localStorage['app']`、H5 读 `localStorage['h5-app']`）→ 历史键（`language` / `h5:language`）→ H5 再回退 `navigator.language` → 默认 `zh-CN`。

## PC 管理端

- 语言包与词条：**shared** 侧见 `packages/shared/src/locale/messages/*.ts`（由 `mergeSharedLocaleMessage` 懒加载）；**Admin** 装配见 `apps/pc/pc-admin-template/src/locales/index.ts`；**H5 业务覆盖**见 `apps/h5/h5-template/src/locales/bundles/`。
- 启动顺序：须在 `app.use(i18n)` **之前**完成首屏语言的 `loadInitial*I18n()`（见各端 `main.ts`）；Element Plus / Vant locale 与 `app` store 对齐（与 [架构说明](./architecture.md) 中 bootstrap 一致）。
- 与主题、布局相关的「界面语言」应通过**单一数据源**（如 `app` store 中的 `language`）驱动，避免多处硬编码。

## 开发约定

- 新页面文案优先走 i18n 词条，**避免**在模板中写死大段中文/英文；公共词条放在共享 locale 分模块维护。
- 与后端联调的「可翻译字段」由接口返回时，前端的展示与格式化（日期、数字）仍通过 `dayjs` / 当前 locale 处理。

## 与权限、主题的关系

- 语言切换**不改变**权限与路由；仅影响 `ElMessage`、表单校验提示等展示语言。
- 若需随系统深浅色切换**组件库**的文案资源，请保持与 Element Plus / Vant 的 API 推荐用法一致（见 [主题与品牌切换](./theme.md)）。
