# 无障碍与可用性

本模板**不替代**产品级的无障碍（a11y）专项审计，但工程上建议与 Element Plus、Vant 的推荐用法一致。

## 一般约定

- 交互组件优先使用**组件库**提供的可访问能力（焦点管理、ARIA 属性、键盘操作）。
- 主题与色对比度在 [主题与暗黑模式](./theme.md)、[Design Token](./design-tokens.md) 中可统一调整；**对比度**需满足你们目标合规等级（如 WCAG 2.1 AA）。
- 图表、自绘区域请补充**文本说明**与**键盘**可达路径，避免仅依赖色块传达状态。

## 与国际化

- 避免仅通过颜色/图标区分成功与失败，配合文案与 [国际化](./i18n.md) 键共同表达。

大改业务组件时，将可访问性需求纳入侧栏 [组件说明](/components/page-container) 的变更说明，便于联调与回归。
